# Vaishali Restaurant - Heritage Redesign by Desynor

A premium, modern redesign of the iconic [Vaishali Restaurant](https://www.vaishalihotel.in/) website, reimagined to capture the essence of a "Garden Sanctuary" and its rich Pune heritage.

## The Concept

This project, executed by **Desynor**, focuses on elevating the digital presence of Pune's most beloved South Indian landmark. We moved away from a traditional layout to a high-end, visual-first narrative that reflects the restaurant's status as a cultural sanctuary.

### Key Enhancements
- **Premium Aesthetic**: A custom color palette (Forest Green, Sage, Ivory, Peach) and refined typography (Fraunces, Playfair Display) that evoke a sense of legacy.
- **Story-Driven History**: A completely redesigned "Our History" page featuring a fixed sidebar timeline and parallax storytelling.
- **Enhanced Visuals**: Integration of professional, high-quality Unsplash stock photography to replace AI-generated or temporary assets.
- **Unified Branding**: Subtle botanical watermarks and heritage-inspired UI components used across all 5 core pages.
- **Optimized Performance**: Built with Next.js for lightning-fast loads and smooth micro-interactions.

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS (with custom design tokens)
- **Language**: TypeScript
- **Icons**: Material Symbols Outlined
- **Fonts**: Google Fonts (Inter, Work Sans, Fraunces, Playfair Display)

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
